# Hiking Survey
Analyzed a number of opinions to determine their sentiment score.
You used the [Natural Language framework](https://developer.apple.com/documentation/naturallanguage) to score text as positive, negative, or moderate and assign it a numeric value. Then used a chart to depict the scores in an informative visual. 
Reflect on how these techniques can be scaled to work with even larger amounts of text.

### Topics and skills covered
- Displaying a large number of reusable views with `ScrollView`
- Using `NLTagger` for text sentiment analysis
- Displaying your data in a `Chart`
- Using `GeometryReader` to get real-time layout data about views
